# 标注规范：「干净」

> 版本 v3（2026-10-05）｜依据：D-05、D-06、D-07｜v3 修改：正面的环境评价都算干净；"院子打理得好"算公共区域干净；被子很香算床品干净｜v2 修改：规则 8 改为"笼统好评算干净"，新增「整体（笼统）」对象，标注表改为每个对象一列
> 结构参考 SemEval ABSA 标注规范（实体 # 属性，如 `ROOMS#CLEANLINESS`）
> 标注时**不看模型的答案**，只按本规范独立判断。遇到拿不准的，写进「备注」，不要硬判。

---

## 一、任务定义

读一条酒店评论，回答两个问题：

1. **这条评论谈到"干净"了吗？**
2. 如果谈到了：**对哪个对象、干净还是不干净、不干净的话是什么问题？**

"干净"指的是：**酒店提供给住客的环境，在住客入住时是否干净。**

---

## 二、判断流程（决策树）

每条评论都按这个顺序判断：

```
第 1 步：评论里有没有描述"干净 / 不干净"的具体内容？
   │
   ├─ 只笼统说"环境好"，全文没有具体提到卫生 → 记【整体（笼统）·干净】，结束
   ├─ 没有（只说"住得舒服""很满意""位置好"）→ 标【没谈到】，结束
   │
   └─ 有 → 第 2 步
            │
第 2 步：说的是"酒店提供的环境"吗？
   │
   ├─ 不是（住客自己弄脏的；酒店外面的街道或巷子）→ 这一处不算
   │
   └─ 是 → 第 3 步
            │
第 3 步：说的是哪个对象？（见第三节，5 选 1）
            │
第 4 步：干净还是不干净？如果不干净，是什么问题？（见第四节）
            │
第 5 步：评论里还谈到别的对象吗？有 → 回到第 3 步，再记一条
```

---

## 三、对象（6 选 1）

| 对象 | 包括 | 例子 |
|---|---|---|
| **房间** | 房间整体、地面、桌面、窗台；**泛指**"酒店很干净""卫生很好"也归这里 | "房間十分乾淨"、"卫生：打扫的很干净" |
| **床品** | 床单、被子、被罩、**枕头** | "床單被罩潔白如新"、"被子裏面一股臭味" |
| **卫生间** | 马桶、淋浴、浴室、洗漱台、地漏 | "衞生間一股尿騷味"、"連洗漱台的水漬都擦凈" |
| **公共区域** | 大堂、走廊、院子、泳池、电梯、餐厅（**酒店范围内**） | "泳池虽小，但维护得很干净"、"大堂都是柳絮" |
| **用品** | 毛巾、浴巾、杯具、水壶、拖鞋 | "水壺裡麪都是水垢" |
| **整体（笼统）** | 只笼统说"环境好"，**全文没有具体提到卫生或任何对象的干净程度** | "環境服務很好"、"服務好 環境也行" |

> 为什么要单独设一类：笼统的"环境好"和"床单洁白如新"说服力不同。分开记录，结论里才能说清楚"其中 X 条只是笼统好评"。对应 SemEval 的 GENERAL 类别。

## 四、态度与问题类型

| 态度 | 什么时候标 | 例子 |
|---|---|---|
| **干净** | 明确说干净、卫生好、整洁、没有异味 | "乾淨整潔"、"沒有一點異味"、"一塵不染" |
| **不干净** | 明确说脏、有异味、有毛发污渍、有虫；否定句"不太干净" | "不太乾淨"、"房間有頭髮" |

标"不干净"时，**再选一个问题类型**：

| 问题类型 | 包括 | 例子 |
|---|---|---|
| **气味** | 烟味、霉味、臭味、尿骚味、异味 | "房间有点烟味" |
| **毛发污渍** | 头发、水垢、污渍、灰尘 | "在枕上和枕頭上都有頭髮" |
| **虫害** | 蚊子、蟑螂、蜘蛛、苍蝇 | "水池裡跑出來蜘蛛" |
| **未说明** | 只说了"不干净""卫生不行"，没说具体问题 | "就是衞生不是太乾淨" |

## 五、判断规则

| # | 规则 | ✅ 算 | ❌ 不算 / 反例 |
|---|---|---|---|
| 1 | **不同对象，分开标** | "床很干净，但卫生间有味" → 床品·干净；卫生间·不干净·气味 | 不要合成一个"好坏参半" |
| 2 | **补救不能抵消问题** | "房间有烟味，后来换了房" → 房间·不干净·气味 | 不能因为换了房就标干净 |
| 3 | **否定掉负面，算干净** | "沒有一點異味" → 房间·干净 | — |
| 4 | **比较句按结论判** | "衞生比我想的要好" → 房间·干净 | — |
| 5 | **否定句算不干净** | "不太乾淨""不算干净" → 不干净 | — |
| 6 | **住客自己弄脏的不算** | — | "孩子流鼻血弄到床上" → 不算 |
| 7 | **酒店外面的环境不算**（试标中一致） | — | "從大路進去要經過一排放滿垃圾筒的巷子" → 不算（巷子在酒店外面） |
| 8 | **有具体说法看具体说法；只有正面的环境评价（"环境好""环境也行""环境安静优雅"），全文没提卫生，就算干净**（2026-10-01 确认，10-05 放宽到所有正面环境评价） | 只说"環境服務很好" → 整体（笼统）·干净；"環境不錯，就是衞生不太乾淨" → 房间·不干净·未说明（以具体说法为准，不再记整体） | 判断依据是**全文有没有具体提到卫生**，不看评论长短 |
| 9 | **舒适不等于干净**（试标中一致） | — | "床品很软""住得很舒服" → 没谈到 |
| 10 | **洗护用品香不香不算**（2026-10-05 确认） | — | "沐浴露的味道很好闻" → 没谈到（属于用品质量） |
| 11 | **打扫服务和设施新旧不算** | "保洁到位""房间收拾得妥帖" → 房间·干净（说的是打扫的**结果**） | "每天都来打扫"（说的是服务频率）、"设施老旧" → 不算 |
| 12 | **潮湿不算不干净**（2026-10-21 确认，D-09） | — | "房间非常潮湿""床单是潮的" → 不算；但有**霉味、潮味**（"smelt damp"）仍算气味·不干净 |
| 13 | **笼统的正面评价算干净，但标为"笼统"**（2026-10-21 确认，D-10；边界按 D-11 方案 B） | 对环境或院子**整体**的正面描述，包括氛围和安静（"环境安静""院落清幽雅致""小院很温馨""古色古香"）；对象的笼统好评（"床品超赞""杯具摆得整整齐齐""院子打理得好"）。归类：院子、小院、院落 → 公共区域 `干净-笼统`；房间 → 房间 `干净-笼统`；只说"环境" → 只说环境好 | 设施的大小或有没有（"巨大浴缸""空间很大""有天台、露台"）；房间装饰风格（"布置温馨""简约雅致"）；舒适（"睡得香""住得舒服"）；整体满意（"很满意"）；酒店外面的环境（"周边安静"） |

## 六、疑难情况解答

| 情况 | 怎么标 |
|---|---|
| 一条评论对同一个对象说了两次，比如"房间干净……房间一尘不染" | 只标一次 |
| 同一个对象既说干净又说不干净，比如"房间整体干净，但角落有灰" | 标两条：房间·干净；房间·不干净·毛发污渍 |
| 被罩"洁白如新" | 床品·干净（说的是干净的状态） |
| "被褥带着阳光晒过的清香"、"被子很香" | 床品·干净（床品本身的气味属于干净的范围；洗护用品的香味才不算） |
| "大堂都是柳絮" | 公共区域·不干净·未说明（环境不干净，算清洁不到位） |
| "院子打理得很好"，没提卫生 | 公共区域·干净（打理得好是正面评价，有具体对象就填对象） |
| 实在判断不了 | 在「备注」写"拿不准"，并写出你的理由。**这比硬判更有价值**，它会帮助我们修改规范 |

## 七、怎么填写标注表

标注表：[标注表.md](标注表.md)，共 60 条，前 10 条是试标（已按 v2 格式转换，请核对）。

**每个对象一列**，谈到哪个对象，就在那一列填写；没谈到的留空。

| 列 | 填什么 |
|---|---|
| **谈到干净？** | 是 / 否 |
| **房间 / 床品 / 卫生间 / 公共区域 / 用品 / 只说"环境好"** | `干净`（具体说了干净）、`干净-笼统`（笼统好评，规则 13），或 `不干净-问题类型`（问题类型：气味 / 毛发污渍 / 虫害 / 未说明） |
| **备注** | 拿不准的情况，或者规范没覆盖到的情况 |

例子：

| 评论 | 谈到干净？ | 房间 | 床品 | 卫生间 | 公共区域 | 用品 | 只说"环境好" |
|---|---|---|---|---|---|---|---|
| "房間衞生做得特別細緻，床單被罩潔白又平整" | 是 | 干净 | 干净 | | | | |
| "在枕上和枕頭上都有頭髮" | 是 | | 不干净-毛发污渍 | | | | |
| "環境服務很好" | 是 | | | | | | 干净 |
| "房間安靜舒適，服務貼心" | 否 | | | | | | |
| "乾淨整潔"（没说是哪里） | 是 | 干净 | | | | | |
| "床品超讚，睡得很香" | 是 | | 干净-笼统 | | | | |

> ⚠️ 最后一列**不是**整条评论的总结论，只用来放"只笼统说环境好、全文没具体提到卫生"的评论。只要评论里具体说了干净或不干净（哪怕没说是哪里），就填在对应对象上；没说是哪里的，填在**房间**。
