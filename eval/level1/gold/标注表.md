先读 [标注规范.md](标注规范.md)（v2）。

- **第 1–10 条是试标**，已经按新格式转换好。请核对「备注」里写了"请确认"的几条，第 1 条请重标
- **第 11–60 条**是正式标注

填写方法：**每个对象一列**，填 `干净`、`干净-笼统`（笼统好评，规则 13），或 `不干净-问题类型`（气味 / 毛发污渍 / 虫害 / 未说明），没谈到的留空。

**最常用的规则**（完整版见[标注规范](标注规范.md)第五、六节）：

| 情况 | 怎么填 |
|---|---|
| 具体说了干净/不干净，但没说是哪里 | 填**房间** |
| 只有笼统的正面评价，全文没提卫生：环境或院子整体的正面描述（"环境安静""小院很温馨""院落清幽雅致"），或对象的笼统好评（"床品超赞""院子打理得好""杯具摆得整整齐齐"） | 提到院子、小院、院落 → 公共区域 `干净-笼统`；提到房间 → 房间 `干净-笼统`；其他对象同理；只说"环境" → 最后一列「只说"环境好"」=`干净`。设施的大小或有没有（"巨大浴缸""有天台"）、房间装饰（"布置温馨"）不算 |
| 有具体说法 | 以具体说法为准，最后一列留空 |
| 舒适（"睡得香""床很软""住得舒服"） | 不算干净 |
| 被子、床品"很香" | 算床品干净 |
| 洗护用品香不香 | 不算干净 |
| 住客自己弄脏的、酒店外面的环境 | 不算 |
| 有烟味后来换了房 | 仍然算不干净（补救不抵消问题） |
